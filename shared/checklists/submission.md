# 投稿检查表

- [ ] 目标会议或期刊、文章类型与官方模板已确认
- [ ] 截止日期与时区已由作者确认
- [ ] 正文、附录、参考文献的页数要求已核对
- [ ] 双盲要求与 PDF 元数据已核对（如适用）
- [ ] 未解析引用、缺图、结果占位符及待定配置已处理
- [ ] 所有结果均有真实数据、代码或证明支持
- [ ] 图表、公式、字体和全部页面已人工检查
- [ ] 伦理、数据、代码、利益冲突声明已按实际情况填写
- [ ] 源码包独立编译通过，归档文件对应当前投稿版本
- [ ] 作者已确认最终提交内容

工作台的编译通过与独立打包验证只检查工程可构建性，不代替上述学术与投稿要求。
